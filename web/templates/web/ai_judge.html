📖 Giao thức AI

AI nhận một JSON từ stdin, in ra một JSON lên stdout. 

// INPUT (stdin)
{
  "board": [[{"player":1,"type":"rock","id":"..."}|null, ...], ...],
  "current_player": 1,        // 1 hoặc 2 — lượt của AI
  "turn_number": 5,
  "legal_moves": [            // CHỈ chọn trong danh sách này
    {"from_row":2,"from_col":0,"to_row":3,"to_col":0,
     "is_capture":false,"captured_type":null}
  ],
  "goal":          {"row":8,"col":8},  // đích của AI (P1)
  "opponent_goal": {"row":0,"col":0},
  "game_over": false
}

// OUTPUT (stdout)
{"move": {"from_row":2,"from_col":0,"to_row":3,"to_col":0}}

Toạ độ 0-indexed. P1 bắt đầu góc trên-trái, đích (8,8). P2 bắt đầu góc dưới-phải, đích (0,0).
